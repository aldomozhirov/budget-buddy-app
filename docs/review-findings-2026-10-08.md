# Review findings, 2026-10-08

Found while documenting `shared/` and `web/`. Nothing here has been fixed yet. Line numbers refer to the files as they are after the documentation pass.

## A. Accessibility bugs in the design-system components

Fix these before screens are built on top of the components. Load the `design-system` skill and add a component test or E2E check for each fix.

| #   | Where                                         | Problem                                                                                                                                                                                | Fix                                                                                                                                        |
| --- | --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| A1  | `web/src/components/BbAmount.vue:26-29`       | When the amount is hidden, `aria-label` sits on a `<span>` with no role. Screen readers usually ignore it and read the dots instead of "Amount hidden".                                | Render the masked dots with `aria-hidden="true"` and add a visually hidden span holding `hiddenLabel`.                                     |
| A2  | `web/src/components/BbListCard.vue:23-27`     | With the default `as="div"`, `label` becomes `aria-label` on a `div` with no role, so it is ignored. The gallery's `<BbListCard label="Family wealth">` hits this.                     | Give it `role="group"` (or `region` for `section`) when `label` is set, or require `as="section"`/`ul` for a labelled card.                |
| A3  | `web/src/components/BbSegmented.vue:89`       | When `modelValue` matches no option, every tab has `tabindex="-1"`, so the control can't be reached by keyboard.                                                                       | Make the first option the tab stop in that case, as `BbChipGroup.vue` already does.                                                        |
| A4  | `web/src/components/BbSegmented.vue:78,87`    | It uses `tablist`/`tab` roles but controls no tab panels.                                                                                                                              | Use `radiogroup`/`radio` with `aria-checked` if it only picks a value; keep tabs only where it switches panels (then add `aria-controls`). |
| A5  | `web/src/components/BbChip.vue:38-46`         | `choice`, `small` and `pill` always get `role="radio"`, even for a chip used on its own outside a radio group. That is invalid ARIA.                                                   | Only set the radio role inside `BbChipGroup` (via a prop or provide/inject); otherwise render a plain button.                              |
| A6  | `web/src/components/BbProgress.vue:29-32`     | `aria-valuenow` is clamped to `max` and `over` isn't exposed, so an overspent budget is read as exactly 100%.                                                                          | Add `aria-valuetext` (for example "€120 of €100, over budget") when `over` is set.                                                         |
| A7  | `web/src/components/BbSwitch.vue:35-36`       | The decorative inner `<span aria-hidden="true">` also has `aria-checked`, which is invalid there.                                                                                      | Replace it with a `data-checked` attribute or a class, and update the CSS selector.                                                        |
| A8  | `web/src/components/BbSheet.vue:37-41`        | Escape is swallowed (`preventDefault`) even when `closable` is false.                                                                                                                  | Only call `preventDefault()` when the sheet will actually close.                                                                           |
| A9  | `web/src/components/BbSheet.vue:79`           | The keydown listener is on `window`, so two open sheets would both react to Escape and both trap Tab.                                                                                  | Keep a stack of open sheets and let only the top one handle keys, or listen on the dialog element.                                         |
| A10 | `web/src/components/BbSheet.vue:48`           | The focus trap checks `aria-hidden` on each element only, not on its ancestors.                                                                                                        | Use `element.closest('[aria-hidden="true"]')`.                                                                                             |
| A11 | `web/src/components/BbSheet.vue`              | Nothing makes the page behind the sheet inert; it relies on `aria-modal` alone, which not every screen reader honours.                                                                 | Set `inert` on the app root while a sheet is open.                                                                                         |
| A12 | `web/src/components/BbConfirmSheet.vue:40-48` | The cancel button gets `text-btn` twice (from `variant="text"` and an explicit `class`). `danger` renders as `secondary` plus a `danger` class instead of BbButton's `danger` variant. | Remove the duplicate class and check the danger button against the design spec.                                                            |

## B. Decisions for the spec (spec 01, Design section 3)

These follow the spec as written, but each needs a deliberate decision. Ask `plan` to settle them in the spec first, then build.

| #   | Where                                                               | Question                                                                                                                                                                                                                                                                         |
| --- | ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B1  | `shared/src/money/minor.ts:2`, `shared/src/money/expression.ts:116` | Amounts may be up to 20 digits, but SQLite `INTEGER` holds at most 9,223,372,036,854,775,807 (19 digits). A 20-digit amount passes validation and then can't be stored. Lower the limit to the 64-bit range, or reject such amounts on the server with a clear validation error. |
| B2  | `shared/src/money/convert.ts:81-87`                                 | A direct or inverted rate is always used, even when it is much older than a route through EUR or USD. A direct rate also wins over a newer inverse rate. Should the newest path win instead?                                                                                     |
| B3  | `shared/src/money/expression.ts:23`                                 | Commas are read as decimal points, so `1,234.56` is rejected as "Invalid number". Is that intended for pasted amounts?                                                                                                                                                           |
| B4  | `shared/src/money/expression.ts:59`                                 | Unary minus is allowed only at the start or after `(`, as spec 01 says, so `1 + -2` and `2 * -3` are rejected. Confirm that's the wanted behaviour.                                                                                                                              |
| B5  | `shared/src/money/iso4217.ts:34`                                    | Codes with no minor unit in ISO 4217 (XAU, XAG, XDR, XTS, XXX and others) get 2 decimals, so `formatMoney(5n, XAU)` shows `XAU 0.05`. Exclude them from the list or give them their own rule.                                                                                    |
